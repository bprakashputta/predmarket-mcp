    03 · Method

    How a pair gets made

    01

    Search the same words

    Each topic runs through both venues' public search. Titles are tokenized, stop words dropped, and long forms folded together ("Federal Reserve" → fed).

    02

    Score by rare words

    Similarity is Jaccard weighted by how rare each word is in the result set, so "nominee" counts for more than "2026". Pairs are one-to-one.

    03

    Refuse look-alikes

    Twelve rules make a pair agree on dates, place, stage (nominee vs confirmed), thresholds, direction, negation and more. Close times must line up too. Each rule has a regression test built from real titles.

    Read before tradingA gap is not an arbitrage. Venues define and resolve events differently: being nominated isn't being confirmed, a price on one date isn't a price on another, and fees, limits and settlement differ. Use a pair as a lead, then read both rule books.
